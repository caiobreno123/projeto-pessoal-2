# Sistema de Controle de Gastos Pessoais

Projeto para Qualidade e Teste de Software.

## Requisitos Funcionais
- Cadastrar gastos
- Listar gastos
- Remover gastos
- Calcular total
- Buscar por categoria

## Requisitos Não Funcionais
- Node.js
- Jest
- GitHub Actions
- CI/CD

## Branches
- main
- develop
- feature/*

## Executar
npm install
npm start

## Testes
npm test
