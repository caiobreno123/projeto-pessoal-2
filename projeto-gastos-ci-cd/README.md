# Projeto Controle de Gastos com CI/CD

## Problema
Dificuldade em controlar gastos pessoais.

## Objetivo
Cadastrar gastos e calcular o total gasto.

## Requisitos Funcionais
- Cadastrar gasto
- Listar gasto
- Calcular total

## Requisitos Não Funcionais
- Node.js
- Jest
- GitHub Actions

## CI/CD
Pipeline executa testes e build automaticamente.
